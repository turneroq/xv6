# Настройка IDE: VSCode

В данном приложении, мы настроим IDE [VSCode][2] для разработки ОС `xv6`.

## Шаг 0. Первый запуск ОС xv6

Убедитесь, что вы выполнили [действия для первого запуска ОС xv6](/doc/setup/initial_setup.md).

## Шаг 1. Установка и настройка VSCode

Установите официальный пакет [VSCode][2] и настройте IDE под себя.

## Шаг 2. Установка расширений VSCode

Установите расширение [cpptools][1].
Установите расширение [git graph][3].
