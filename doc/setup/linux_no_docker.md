# Первый запуск ОС Xv6

Последующая информация основана на [инструкции от разработчиков xv6][1].

В данном приложении описано, как проще всего запустить ОС `Xv6` на вашем компьютере под управлением `Ubuntu`.

`Ubuntu` - широко известный дистрибутив Linux.

## Шаг 1. Установка Ubuntu

### Установить ПО для запуска виртуализированных операционных систем

Вы можете установить и запустить данную операционную систему на виртуальной машине с помощью [Virtual Box][2] или [VMWare][3].

Необходимо скачать и установить одну из этих программ.

### Установить образ операционной системы

Необходимо скачать образ операционной системы [Ubuntu][4].

Далее установить .iso образ в VirtualBox или VMWare. 

Можно воспользоваться данным [гайдом][5] для VirtualBox.


## Шаг 2. Установка необходимых зависимостей в Ubuntu

Выполните данную команду в терминале:
```bash
$ sudo apt-get install git build-essential gdb-multiarch qemu-system-misc gcc-riscv64-linux-gnu binutils-riscv64-linux-gnu 
```

## Шаг 3. Получение исходного кода ОС xv6

Для этого будет использоваться git.
Выполните команду в терминале:
```bash
$ git clone https://github.com/turneroq/xv6.git xv6
```
После выполнения команды перейдите в папку xv6
```bash
$ cd xv6
```

## Шаг 4. Сборка и запуск ОС xv6

Попробуйте собрать, используя команду в терминале:

```bash
make
```

И, наконец, запустите.

```bash
make qemu
```

Вы готовы к работе. Удачи!
